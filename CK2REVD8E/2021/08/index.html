オープンワールドゲームで例えたら

Ruby -> 例えメインストーリーが進んでなくても全ての障害物は退けられる。行ったことがない場所でもファストトラベル可能。Tipsがまるで役に立たない。
Python -> メインストーリーが進んでいない場合は退けられない障害物がある。行ったとしても特定ポイントで開放しない限りはファストトラベル不可。流れが固定されるのでTipsがあると攻略がラクになる。
Golang -> メインストーリーが進んでいない場合は退けられない障害物があるが、味方が大量にいた場合は数の暴力でこじ開ける事が可能。ファストトラベル？そんなものはない。
