修正しました

fyi @ycino
<https://github.com/lambdalisue/fern.vim/pull/355|#355 Fix `E474: Invalid argument: cursorlineopt=number,line` in Neovim nightly>
The cursorlineopt was introduced at patch 8.1.2019 but at that time, the
default value was both and , is not allowed in the value.
After patch 8.1.2029, , is allowed and the default value became number,line.

Neovim nightly (2021/08/01) raise E474 because neovim/neovim#15161
only introduce patch 8.1.2019.

Thanks @yuki-yano

とりあえずこんな感じの設定で。まだまともに使っていないので間違っているところもありそう。
[[plugins]]
repo = 'Shougo/ddc.vim'
depends = ['context_filetype.vim', 'denops.vim']
on_event = 'InsertEnter'
hook_source = '''
  call ddc#custom#patch_global(
      \ 'sources', ['buffer', 'ddc-vim-lsp']
      \ )
  call ddc#custom#patch_global('sourceOptions', {
      \ '_': {
      \   'matchers': ['matcher_head'],
      \   'sorters': ['sorter_rank'],
      \ },
      \ 'buffer': {'mark': 'B'},
      \ 'necovim': {'mark': 'vim'},
      \ 'ddc-vim-lsp': {'mark': 'lsp'},
      \ })
  call ddc#custom#patch_filetype(
      \ ['vim', 'toml'], 'sources', ['necovim', 'buffer'])
  call ddc#custom#patch_filetype(
      \ ['autohotkey', 'cfg', 'git', 'javascript', 'markdown', 'plantuml', 'rst', 'snippet', 'vb', 'xsl'], 'sources', ['buffer'])
  call ddc#custom#patch_filetype(
      \ ['go', 'python'], 'sources', ['ddc-vim-lsp', 'buffer'])
  call ddc#enable()
'''
