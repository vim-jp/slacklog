*Description*

This PR supports rich_text blocks.
Once merging this, you'll be able to handle like following response correctly.


  "blocks": [
    {
      "type": "rich_text",
      "block_id": "XXX",
      "elements": [
        {
          "type": "rich_text_section",
          "elements": [
            {
              "type": "channel",
              "channel_id": "C0123456789"
            },
            {
              "type": "text",
              "text": " hi"
            }
          ]
        }
      ]
    }
  ]
