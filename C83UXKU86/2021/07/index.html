<https://github.com/vim/vim/pull/8299|#8299 Fix and Proposal: buffer name scheme part adjust RFC3986 like rule>
*Problem*

Currently scheme check is not support symbol char ., + and -

*Solution*

This PR is fix above problem under RFC 3986 like scheme rule.
ref : rfc3986

*Details*
old suggest Scheme is defined in RFC 1738 and successor RFC 3986 (supplement RFC 2234)

RFC 1738 rule:


scheme = 1*[ lowalpha | digit | "+" | "-" | "." ]



RFC 3986 rule:


scheme      = ALPHA *( ALPHA / DIGIT / "+" / "-" / "." )



* * *

This PR based on RFC 3986.

new suggest

Add support - in scheme string (start and end do not support).

*Test*
