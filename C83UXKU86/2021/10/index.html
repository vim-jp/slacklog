feedkeys の t の挙動に違和感があるという内容で vim に issue 立てようかと思います。
マクロに記録されるキーがおかしいのではないか？という内容になっています。
 set nocompatible

function! Test() abort
  call feedkeys("\<Ignore>", 'n')
  call feedkeys("foo", 'n')
  call feedkeys("bar", 'nt')
  call feedkeys("baz", 'n')
  call feedkeys("foo", 'n')
  call feedkeys("bar", 'nt')
  call feedkeys("baz", 'n')
endfunction
autocmd InsertEnter * ++once call Test()

1. こういうスクリプトを用意する
2. このスクリプトをソースする
3. qq でマクロの記録を開始してから insert-mode に入る（すると、バッファに foobarbazfoobarbaz が挿入される）
4. insert-mode を抜けて、q でマクロの記録を終了する
5. マクロを実行すると barbaz が挿入される
t フラグが指定しているのは bar に対してだけなので、直感的には barbar になると思われるが、そうならない。

という内容を予定しています。
