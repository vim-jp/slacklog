## line2byte() returns an incorrect value.
**Describe the bug**
If the text property is set to before line 400, the result of line2byte() after line 400 will be an incorrect value.

**To Reproduce**

sample.vim
vim
:call setline(1,range(500))
:echom “before” line2byte(401)
:call prop_type_add(‘vim-test’,{‘bufnr’:1})
:call prop_add(2,1,{‘type’: ‘vim-test’})
:echom “after” line2byte(401)


1. vim -u NONE
2. :source sample.vim

the script result

before 1491
after 1511

**Expected behavior**

:echom “before” line2byte(401) and :echom “after” line2byte(401) show same value.

**Environment (please complete the following information):**
- Vim version [8.2.3325]
- OS: macOS 10.15.7
- Terminal: Alacritty
