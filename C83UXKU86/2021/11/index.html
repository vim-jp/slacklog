<https://github.com/vim-jp/issues/issues/1381|#1381 set や setlocal でオプションを変更すると curswant がリセットされる場合がある>
*不具合の内容*
*現象・ログ*

カーソルの上下移動の際に使われる curswant ですが、 set や setlocal でオプションを変更するとリセットされることがあります

(curswant については setpos や winrestview のヘルプを読みました)

*再現手順*


gvim.exe -u NONE -U NONE -c "call winrestview({'curswant': 10})" -c "echo getcurpos()" -c "set number&" -c "echo getcurpos()"



実行しているコマンドは以下です


call winrestview({'curswant': 10})
echo getcurpos()
set number&
echo getcurpos()


ここでは number を :set-& しましたが、 set number や set nonumber でもリセットされました。
また、 relativenumber や wrap 等でもリセットされました。

ただし、どんなオプションでもリセットされるわけではないようです。

*期待動作*

再現手順の例で言うと、


[0, 1, 1, 0, 11]
[0, 1, 1, 0, 1]



と echo 表示されますが


[0, 1, 1, 0, 11]
[0, 1, 1, 0, 11]



となるのが正しいと思います
