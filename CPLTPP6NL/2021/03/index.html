よく使うもの
prefix s → セッション切り替え
prefix 数字 → 数字のウィンドウに移動
prefix hjkl → pane 間の移動（これはマッピングしている）
prefix " → vertical split
prefix % → horizontal split
prefix [ → visual mode に入る。キーマップにより hjkl に移動、y でヤンクなどができるようにしている
