突然 POST を投げてくるのを防ぐ方法が CSRF token なので。
Reacji Channeler 8日 20:07:53 Slack
https://vim-jp.slack.com/archives/CTHMGMNNS/p1617880033394200
例えば GitHub のどこかのページが脆弱で、ボタン押したらリポジトリが消える画面があったとします。悪意のある誰かがそのボタンを押したと同じになる様な画面を別のサイトに作って form/action だけそっちに向けておいた。そして僕に「このサイトにアクセスしてボタンを押して」と依頼し、僕がボタンを押したら画面が GitHub に遷移して GitHub 上のリポジトリが消えた。これを回避する為に GitHub はいったん削除の前の画面にトークンを付けて表示し、ボタンを押した時にトークンも貰う。POST 側では発番したトークンじゃない場合、もしくはトークンが付いてない場合は弾く。これが CSRF token。
