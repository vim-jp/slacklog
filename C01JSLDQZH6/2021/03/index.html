pyls の jedi や pyright-langserver は stub パッケージが入っているとそれも考慮してくれるようになっています。公式、またはサードパーティの stub パッケージがあればそれを pip でインストールすると補完等ができるようになります。例えば data-science-types を入れる(pip install data-science-types)と numpy, pandas, matlplotlib の補完の効かないものも補完ができます。 numpy は v1.2.0 以降で本体に stub ファイルが含まれるようになっていたり pandas も近い将来に本体に含むようにってのが進んでるようではあります。
