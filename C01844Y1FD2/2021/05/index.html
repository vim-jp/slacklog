monaqa 2日 08:05:53 Slack
長らく解析学から離れてたのであんまし自信ないですが、
(-∞, ∞) を積分区間とするときの広義積分は (-a, b) を積分区間としたときの積分値が a → ∞, b → ∞ としたとき「a, b の近づけ方によらずに」収束する場合に収束すると定義されるはずです。
そうでない場合は広義積分が収束するとはみなされず、 (-a, a) を積分区間としたときの a → ∞ における極限値が主値となります。
今回はたぶん (0, ∞)で積分すると正の無限大に発散し、 (-∞, 0) で積分すると負の無限大に発散するので、全体としては収束しないという判定となります
KosukeMizuno 2日 08:12:12 Slack

monaqa 2日 08:12:16 Slack
どうして積分が 2 π i * (a + ib における留数) の結果と一致しないんだ、という話ですが、
「複素平面の上半分を回る積分」で一般的にとられる積分路は（実軸上に極がないとき）
C1: 実軸を -R から R の方向に結ぶ経路
C2: 半径 R の円周上の上半分（虚部 >= 0 に相当する部分）を反時計回りにまわる経路
の2つを考えて、C = C1 + C2 の周回積分を考えることが多いと思います。
R → ∞ としたときに ∫C2 f(z) dz の値が0に収束してくれれば ∮C f(z) dz の値（これは留数定理で求まる）が∫C1 f(z) dz と等しくなるので問題ないんですが、
今回は分母の次数が分子の次数 + 2 よりも小さいので、 ∫C2 f(z) dz の値が0に収束しないんですよね。たぶん。
