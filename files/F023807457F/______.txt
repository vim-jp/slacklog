# zeno.zsh will improve your shell life!

zeno.zsh is a plugin to extend frequently used functions in zsh.
https://github.com/yuki-yano/zeno.zsh

zeno.zsh depends on Deno for its operation.

## Main features

- Abbrev snippet
- Insert snippet
- Fuzzy completion with fzf

## Demo

## Features

### Abbrev snippet

Automatically expands the snippet using the keyword you set instead of the zsh alias.
This will improve history and allow you to perform fuzzy completion.
If you include a placeholder in the snippet, the cursor position will be moved to the placeholer.

### Insert snippet

You can insert a snippet with fzf at the cursor position.

### Fuzzy Completion

When a match is found for a given regular expression, fzf completion will be performed instead of the normal completion.
Git completion is builtin in zeno.zsh.

## User settings

You can configure snippet and completion settings in YAML.
An example of each is shown below.

````
snippets:
  - name: git status
    keyword: gs
    snippet: git status --short --branch
```

```
completions:
  - name: kill
    patterns: 
      - "^kill( -9)? $"
    sourceCommand: "ps -ef | sed 1d"
    options:
      --multi: true
      --prompt: "'Kill Process> '"
    callback: "awk '{print $2}'"
```
