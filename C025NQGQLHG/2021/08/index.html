Adobe XDで編集作業するとき、全アートボードを画像ファイルに書き出して、それをGitリポジトリにコミットしておけば、マウスやキーボードの誤操作で自分が知らないうちに何か変更してしまっても気がつけるようになりました。
より厳密にやりたい場合は、
GitHub Issue作成 → XDで作業（編集、書き出し、コミット）→ PR作成 → 差分確認してマージ
とすれば、共同編集者（主に非プログラマ）にも変更差分が確認しやすくなります。ただ、XDファイル自体の共同編集をするとこのフローは無理でしょうね。
