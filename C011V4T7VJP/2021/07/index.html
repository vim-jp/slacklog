gh+fzfでユーザーのレポジトリ一覧からクローンが便利って話ありましたけど、以下のように、issue一覧をプレビューして、確定したらweb版を開くのも超便利……！
function ghissue() {
  gh issue list \
    | fzf --preview 'echo {} | /bin/grep -Eo "^[0-9]+" | xargs gh issue view' \
    | /bin/grep -Eo "^[0-9]+" \
    | xargs gh issue view --web
}
