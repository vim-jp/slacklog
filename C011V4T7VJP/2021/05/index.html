> fork ではなくコピーで作られた（履歴が一致しない）リポジトリ
ちなみにこのリポジトリを最初にみたときは激おこぷんぷん丸でしたが、
ちゃんと Git はこういった運用を想定しているらしい。
（Git は全履歴のスナップショットを保存する関係でサイズが膨大になりうるから）

git replace というコマンドがあり、リポジトリ Ry がリポジトリ Rx のコピーであり、
Rx のあるコミット Cx と Ry の initial コミット Cy_init のファイルツリーが一致するとき、
リポジトリ Y 上で
git replace Cy_init Cx

とすると、 リポジトリ Ry のログは Cy_init が Cx に置き換わり、Rx の歴史も遡って見ることができるようになります。
