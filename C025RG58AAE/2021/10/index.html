*Realistic issue*

In real world, we faced start-up time issue of Vim/Neovim that use ddc
that relies on denops that built on Deno.

The diagram below illustrates the architecture and relationship among Vim,
denops, and ddc. In short, we found that ddc start-up is slow because it
imports its plugins by dynamic imports (A box with # in the diagram.)


Vim --- Run ---> denops
                    |
                    +-- Invoke --> Worker            #######################################
                    |                |               #                                     #
                    |                +-- dyn import -#-> ddc                               #
                    |                                #    +-- dyn import --> ddc-around    #
                    |                                #    +-- dyn import --> ddc plugin A  #
                    |                                #    +-- dyn import --> ddc plugin B  #
                    :                                #    :                                #
                    |                                #                                     #
                    |                                #######################################
                    +-- Invoke --> Worker
                    |                |
                    |                +-- dyn import --> denops plugin A
                    |
                    +-- Invoke --> Worker
                    |                |
                    |                +-- dyn import --> denops plugin B
                    :



So we tried to investigate the reason of this performance issue. For example,
ddc-around is a ddc plugin and
denops/@ddc-sources/around.ts is the file that imported. We measured the
performance for importing that file like.


async function main() {
  const t = performance.now();
  await import(
    "<https://raw.githubusercontent.com/Shougo/ddc-around/main/denops/%40ddc-sources/around.ts>"
  );
  console.log(performance.now() - t);
}
await main();


And we found that it took approx *200 ms* to import that single file. We need
to import multiple similar files, mean that we need to wait *several seconds*
to get completion feature from ddc after we start up Vim.
