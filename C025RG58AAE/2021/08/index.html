console.log("patternB", "Success".match(patternB));
console.log("patternC", "Success".match(patternC));


Above code shows


patternA [ "Success" ]
patternB [ "" ]
patternC [ "" ]



I understand that the method is deprecated but I think Deno should warn and keep the object.

Tested with Deno v1.13.0 on macOS.
