この include のやつ、文字列の場合は部分文字列を探すけど、配列の場合は要素を探す。利便性とかを考えると正しいとは思うんだけど、どうも一貫性がないような気もしてしまう。
どういうことかと言うと、 include('abcde', 'bcd') とあったら、abcde は bcd の並びを含んでいるので true になる。
では include(['a', 'b', 'c', 'd', 'e'], ['b', 'c', 'd']) はどうかと言うと、左の配列は ['b', 'c', 'd'] と言う配列を要素に含んでいないので false になる。

It would be nice if there was an option to include the output of :messages (with the exception of the Maintainer line at the beginning) along with the assertion errors in the reporter output for failing tests.
