Vim プラグインのテストで、system() で実行されるコマンドの引数についてテストがしたく、そのために system() に渡すコマンドの最初の部分(実行するコマンド部分)は入れ替えられるようにして、このコマンドをゴニョゴニョして渡される引数のテストができないか考えています。
シェルが Bash の場合、
let tempfile = tempname()
let cmd = printf('dummy() { printf "%%s\n" "$@" > %s; }; dummy', tempfile)

みたいな感じにして後で tempfile の中身を見たらいけたんですけど、Windows (cmd.exe) でどうしようか…と言うところで悩み中。いい案ある人いたら知恵を借りたいです。最悪 Windows でのテストはスキップかな…
