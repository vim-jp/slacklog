> 私がよく遭遇する質問の1つは、「2015年にのみ標準化されたHTTP / 2の直後にHTTP / 3が必要なのはなぜですか？」です。そもそも新しいHTTPバージョンが本当に必要ではなく、基盤となる伝送制御プロトコル（TCP）のアップグレードが必要であることに気付くまで、これは確かに奇妙です。
...
> 結局のところ、TCPだけでなくHTTP /1.1にも問題がありました。作業を分割し、最初にHTTP / 1.1を「修正」することを選択しました。これにより、現在はHTTP / 2になります。それが行われると、TCPの置き換えで作業を開始できます。TCPは現在QUICです。当初は、QUIC上でHTTP / 2を直接実行できることを望んでいましたが、実際には、実装が非効率になりすぎます（主に機能の重複が原因です）。
>
> 代わりに、HTTP / 2は、QUICと互換性を持つように、いくつかの重要な領域で調整されました。この微調整されたバージョンは、主にマーケティング上の理由と明確さのために、最終的にHTTP / 3（HTTP / 2-over-QUICではなく）と名付けられました。そのため、HTTP /1.1とHTTP / 2の違いは、HTTP / 2とHTTP / 3の違いよりもはるかに大きくなります。
