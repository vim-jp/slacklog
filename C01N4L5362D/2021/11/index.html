<https://github.com/denoland/deno/issues/12519|#12519 Dynamic (remote) import is quite slow and seems not cached>
I'm not sure if it's known but it seems remote dynamic import is quite slow. For example


async function main() {
  const t = performance.now();
  await Promise.all([
    import("<https://deno.land/x/denops_core@v2.0.3/mod.ts>"),
  ]);
  console.log(performance.now() - t);
}
await main();


Above took approx. 55 ms with deno run -A --no-check ./test.ts. It seems the number of remote imports in the target file affect the performance.

Additionally, it seems remote dynamic import does not use cache. For example
