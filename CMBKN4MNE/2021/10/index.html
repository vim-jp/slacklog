qryxip 20日 22:39:26 Slack
補足し忘れていましたが、&や*や[]で参照をワンライナーで変数に入れる分には許されます。
> If the & or &mut operators are applied to a value expression, then a temporary value is created.
https://doc.rust-lang.org/stable/reference/expressions/operator-expr.html#borrow-operators

私はよくこんな感じに書いたりします。
// OK
let s = { "contents".to_owned() }; // String
let _ = { s };

// OK
let s = &{ "contents".to_owned() }; // &String
let _ = { s };

// OK
let s = &*{ "contents".to_owned() }; // &str
let _ = { s };

// OK
let s = &{ "contents".to_owned() }[..]; // &str
let _ = { s };

// OK
let (s,) = (&{ "contents".to_owned() },);
let _ = { s };

// Error
//let s = { "contents".to_owned() }.as_str();
//let _ = { s };

// OK (使われていないため)
let s = { "contents".to_owned() }.as_str();

これを悪用すれば一応マクロを使わずともこんなこともできますね。
